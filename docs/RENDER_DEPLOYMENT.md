# Deploy the Scorpions backend

1. In a Supabase **Free** project, open **Connect**. Copy the Session pooler PostgreSQL URI (port 5432) into your password manager as `DATABASE_URL`. Substitute the URL-encoded database password for the password placeholder. Use the database and host from that project. The application requires TLS, a role with CREATE on the database and ownership of the application's scorpions schema and tables. Leave the scorpions schema outside the Data API's exposed schemas.
2. Copy the project URL from Connect as `SUPABASE_URL`. Use the HTTPS origin ending in .supabase.co without a trailing slash. Under **Settings → API Keys**, create a backend secret key for this service and save it as `SUPABASE_SECRET_KEY`. The adapter sends this key in the apikey header. Keep it out of the frontend and Git.
3. Under **Storage → Buckets**, create **scorpions-documents** with **Public bucket** off. Leave anonymous and authenticated browser roles without object access policies for this bucket. The backend handles per-user authorization. If configuring bucket restrictions, permit application/octet-stream and sizes up to 20 MiB.
4. From the repository root, with its Python dependencies installed, run `python -m scripts.render_preflight --prompt`. Enter the three values in the masked local prompts. This uses a temporary signing key, checks PostgreSQL TLS and database privileges, reads bucket metadata, and writes, retrieves and deletes one synthetic object. Proceed after the command exits successfully.
5. In the intended Render workspace, open **New → Blueprint**, connect **teamscorpionsoff-ship-it/SCORPS-AI**, select **deploy/render-free** as the Blueprint branch, and use **render.yaml** as the Blueprint path. Use **scorpions-ai** as the Blueprint name. Enter the same three values in the secure prompts for the variables marked sync: false. Review the preview for one Free Python web service named **scorpions-ai-api**. Use a free workspace without a payment method or paid overages. Click **Deploy Blueprint** after the checks and preview pass.
6. The blueprint generates APP_SECRET_KEY, fixes APP_ENV=production and LLM_PROVIDER=demo, and sets SUPABASE_STORAGE_BUCKET=scorpions-documents. Leave FRONTEND_ORIGIN unset for backend-only operation. After the frontend exists, set it to its exact HTTPS origin without a trailing slash. The repository root is the build directory, the build command is `python -m pip install -r requirements.txt`, the start command is `uvicorn app.main:app --host 0.0.0.0 --port $PORT`, and the health path is `/health`.
7. Once Render reports Live, copy the actual HTTPS origin displayed on the service page. In PowerShell, set `$env:API_BASE_URL` to that origin and run `python scripts/deploy_check.py`. It requires production health and rejects anonymous access to /api/me. Record the verified URL and deployed commit.
