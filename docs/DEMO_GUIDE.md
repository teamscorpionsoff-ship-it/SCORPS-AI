# Demo guide

1. Start using `run.bat` on Windows or `./run.sh` on Linux/macOS.
2. Open `http://127.0.0.1:8501`, create a local account, and add two tasks.
3. Ask the assistant to add a task and request a plan.
4. Save and delete an explicit memory; upload a sample document.
5. Show Settings and Email & Calendar to demonstrate honest disconnected states.

All local data and simulated planning are clearly demo operations. No email is sent, calendar is not changed, and research does not fabricate sources.
