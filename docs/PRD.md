# Product requirements

Scorpions AI is a personal staff workspace for the A3 “A personal staff for everyone” direction. It combines conversation, tasks, tentative planning, user-controlled memory, research, multi-step approval tracking, email/calendar connection states, and document management.

MVP acceptance: a user can register, sign in, manage their own tasks and memories, request deterministic demo assistance, upload supported text-bearing documents, and inspect disconnected integrations without false claims of external actions.

Limitations: PostgreSQL is supported for hosted data. Hosted verification and object storage are pending. Email, calendar, live web research, and live LLM execution are disconnected.
