# Scorpions AI engineering instructions

- Keep all credentials in environment variables; never log or return secret values.
- Preserve the local demo mode and zero-cost default. Never invoke paid providers automatically.
- Keep user data isolated by authenticated user and avoid consequential external actions without approval.
- Prefer small typed Python modules, validated API boundaries, and deterministic business logic.
- Update docs when behavior, configuration, or deployment assumptions change.
- Do not claim provider integrations or deployment have been verified without actual credentials and access.
